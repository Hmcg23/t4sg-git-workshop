# Answers

1. Git is a version control system that runs locally on your computer and tracks code changes. GitHub is a hosting platform and service where you can push those changes to share and collaborate with others publicly.
2. Version control is important because it allows multiple developers to implement features without affecting others' work. It makes collaboration much easier and prevents conflicting changes.
3. The `git log` command lets you view a branch's commit history.
4. `git branch` lists all branches in your local repository, while `git branch -r` lists the remote-tracking branches (branches from the remote repository).
5. You can use a `.gitignore` file to specify files and directories that Git should ignore and not track.
